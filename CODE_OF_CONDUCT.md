# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work. Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or any other project space.

Report unacceptable behaviour to support@ssojet.com. Every report is reviewed and kept confidential. Maintainers may remove comments, close threads, or ban anyone who breaks these rules.
